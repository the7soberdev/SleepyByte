# Roadmap

The original interface outline groups capabilities into these delivery phases.

1. **Foundation:** application shell, navigation, preferences, and health status.
2. **Case management:** investigations, entities, evidence, notes, and findings.
3. **Core analysis:** domain, IP, DNS, URL, email, metadata, and hash tools.
4. **Web intelligence:** certificates, public search, HTTP/TLS, and asset discovery.
5. **Analysis:** feeds, IOC workflows, ATT&CK reference, graph, timeline, and correlation.
6. **Integrations and exports:** provider configuration, reports, and export formats.
7. **Diagnostics:** runtime diagnostics and logs.

Treat this as an initial planning outline; confirm scope against the running implementation before scheduling work.
